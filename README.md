SyncClipboard 是一款跨设备剪贴板同步工具，支持 Windows、macOS、Linux 和 Android，也可通过快捷指令在 iOS 和 iPadOS 上使用。在一台设备上复制的文本、图片和文件，可以直接在另一台设备上粘贴。SyncClipboard 还支持剪贴板历史记录管理与同步，并提供图片格式兼容等本机剪贴板优化功能。更多信息请参阅[使用文档](https://syncclipboard.pages.dev/)。
